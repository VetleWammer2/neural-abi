# Canonicalization and recognition

The mandatory frontend is strict `torch.export.export`. NeuralABI then calls
`ExportedProgram.run_decompositions({})`: the empty table functionalizes local mutation without
immediately lowering recognizable operators. Mutation of parameters, buffers, or user inputs is
rejected from the graph signature.

The versioned rewrite registry normalizes exact ATen linear/matmul/addmm, view/reshape, axis
movement, explicit splits, elementwise operations, embedding, softmax, and RMS primitives. Rules
have exact target and structural preconditions; unknown operations are retained and must be
accepted by a recognizer or cause an unsupported result.

Decoder recognition requires structural evidence for embedding, RMS mean-square normalization,
rotary sine/cosine application, score matmul, causal mask, softmax, value aggregation, GQA
expansion, residual additions, SwiGLU, final normalization, and vocabulary output. Layer order is
the topological sequence of attention softmax boundaries. Q, K, and V roles come from score and
value dataflow. Fused order comes from the branch split that feeds those roles. Names are not read
when name hints are off.

Supported causal masks are an explicit `masked_fill` or an additive mask generated by a boolean
`where` with a finite dtype minimum. Supported fused QKV is either a last-axis flat split or a
rank-five `[batch, sequence, kv_groups, pieces, head_dim]` group split.
